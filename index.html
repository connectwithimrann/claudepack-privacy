ClaudePack

Privacy Policy

Last updated: September 26, 2026

ClaudePack is a browser extension that adds productivity tools to Claude.ai, including usage tracking, conversation metrics, prompt templates, prompt token estimates, conversation forking, message bookmarks, chat exports and usage reset alerts. This Privacy Policy explains what information ClaudePack accesses, how it is used, where it is stored and whether it is shared.

1. Information ClaudePack Accesses

ClaudePack may access information available within Claude.ai that is necessary to provide its features. This may include:

  • Claude conversation messages
  • User prompts
  • Claude responses
  • Conversation metadata
  • Conversation identifiers
  • Message identifiers
  • Claude usage information
  • Usage reset times
  • Estimated token and context information
  • Saved prompt templates
  • Message bookmarks
  • ClaudePack settings and preferences

ClaudePack only accesses this information when necessary to provide the extension's user-facing features.

2. How Information Is Used

ClaudePack uses this information to provide features including:

  • Displaying Claude session and weekly usage
  • Displaying usage reset times
  • Showing conversation input, output, context and message statistics
  • Estimating prompt token counts
  • Providing and managing prompt templates
  • Saving custom prompts
  • Forking conversations from selected messages
  • Bookmarking messages
  • Jumping back to bookmarked messages
  • Exporting conversations
  • Maintaining local usage history
  • Providing usage reset notifications

ClaudePack does not use this information for advertising, profiling or purposes unrelated to the extension's functionality.

3. Local Storage

ClaudePack is designed to be local-first. Information such as the following may be stored locally in your browser using browser storage:

  • ClaudePack settings
  • Saved prompts
  • Custom prompt templates
  • Message bookmarks
  • Usage history
  • Reset notification state
  • Extension preferences
  • Fork metadata

This locally stored information remains on your device unless a feature explicitly states otherwise.

4. Claude Conversation Content

ClaudePack may process the content of Claude conversations in your browser to provide features such as conversation statistics, bookmarks, conversation forking and exports.

ClaudePack does not operate a server that stores copies of your Claude conversations. Conversation content processed for these features is handled locally in your browser.

ClaudePack does not sell Claude conversation content or use it for advertising.

5. Usage Information

ClaudePack may read Claude usage information made available through Claude.ai in order to display session usage, weekly usage, reset times and usage history.

ClaudePack may cache this information locally in your browser so that usage tracking and reset notifications can function correctly.

ClaudePack does not sell this information or use it to create advertising profiles.

6. Prompt Templates and Bookmarks

Custom prompts, saved prompts and message bookmarks are stored locally in your browser. ClaudePack does not sell or share this information with advertisers.

7. Chat Exports

When you choose to export a Claude conversation, ClaudePack generates the requested export for you.

Exports may include formats such as Markdown, Word or JSON.

Exported files are generated only when requested by the user and are saved to the user's device. ClaudePack does not upload exported conversations to a ClaudePack server.

8. Notifications

If enabled, ClaudePack may use browser notifications to inform you when Claude usage limits have reset or become available again.

Notification state and related usage information may be stored locally in your browser.

9. Data Sharing

ClaudePack does not sell user data.

ClaudePack does not transfer user data to data brokers.

ClaudePack does not use user data for personalized advertising, retargeting or interest-based advertising.

ClaudePack does not allow humans to read your Claude conversations except where required by law or when you explicitly provide information for support purposes.

ClaudePack does not transfer Claude conversation content to third parties for unrelated purposes.

10. Anthropic and Claude.ai

ClaudePack operates on Claude.ai and interacts with information already available to you through Claude.

Your use of Claude.ai remains subject to Anthropic's own terms and privacy practices.

ClaudePack is an independent extension and is not affiliated with, endorsed by or sponsored by Anthropic. Claude is a trademark of Anthropic.

11. Data Retention

Locally stored ClaudePack data remains in your browser until:

  • You remove the relevant saved information
  • You clear the extension's browser storage
  • You uninstall ClaudePack
  • ClaudePack removes the information as part of its normal functionality

ClaudePack does not maintain a server-side archive of your Claude conversations.

12. Data Security

ClaudePack is designed to minimize the amount of information it accesses and stores.

Where network communication is required for extension functionality, secure HTTPS connections are used where applicable.

ClaudePack requests only browser permissions that are necessary to provide its features.

13. Children's Privacy

ClaudePack is not specifically directed toward children and does not knowingly collect personal information from children.

14. Changes to This Privacy Policy

This Privacy Policy may be updated when ClaudePack's functionality or data practices change.

The updated policy will be published at this same URL with a revised "Last updated" date.

15. Limited Use

ClaudePack's use of information received from browser permissions and Claude.ai is limited to providing and improving ClaudePack's user-facing features.

  • User data is not used or transferred for personalized advertising.
  • User data is not sold.
  • User data is not used for creditworthiness or lending purposes.
  • Human access to user data is prohibited except when the user explicitly provides data for support, when required for security purposes, when required by law, or when data has been aggregated and anonymized for permitted internal operations.

ClaudePack's use and transfer of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.
